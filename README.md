### How often is OmniPatch updated?

Updates are released within 48 hours of major version releases for any supported application to ensure continued functionality.

### Do I need to disconnect from the internet to use OmniPatch?

No, internet connectivity is required for the patcher to download the latest patch definitions and verify file integrity.

### Will this affect my existing saved data or settings in the AI apps?

The process only modifies executable files and should not touch user data, settings, or project files. Backup is still recommended.

### Can the AI companies detect and block the activated features?

While possible in the future, updates to OmniPatch are designed to match changes in detection methods.

### Is there a version for macOS or Linux?

Currently, OmniPatch is a Windows-only utility. Development for other platforms is being evaluated for future releases.
